# 鼠标猜测玩法 · 字段设计文档

> 状态(2026-09 更新):完整字段体验版与**难度分层均已落地** —— `easy`/`normal`/`hard` 三档难度池上线(`server/src/difficulties.ts` + `mouse_difficulties` 成员表),输入联想按池过滤,另有鼠标级 `is_enabled` 停用开关。本文档写作时分层尚未实施,§3 为当时的历史讨论,现状以 README 与代码为准。
> 目标:让「猜鼠标」玩法对不同难度玩家都好玩 —— 大众玩家零门槛上手,硬核玩家有深度可挖。
> 范围:仅设计玩法 **展示与判定用到的字段集合**。胜负判定已不限于 `id` 相等 —— 同规格兄弟款同样判胜,见 §6。

---

## 1. 背景与现状

- 判定逻辑集中在 `server/src/services/gameService.ts` 的 `compareGuess()`。
- 当前判定字段固定 10 个,且**不随难度(mode)变化**:品牌 / 品牌属地 / 形状 / 尺寸 / 重量 / 长度 / 宽度 / 高度 / 连接 / 传感器。
- 胜负判据:`correct = guess.id === target.id || 同规格兄弟款`(规格指纹一致的不同条目,见 §6);属性反馈是**辅助缩范围**,一般不是胜负判据。
- 三档难度 `easy` / `normal` / `hard`(小白 / 潮男 / 扫地僧),按 `mouse_difficulties` 成员表分层,池子累进(easy ⊂ normal ⊂ hard)。

## 2. 已拍板的决策(截至当前讨论)

### 2.1 字段要去掉的
- ❌ **DPI** — 太硬核,且与传感器高度相关
- ❌ **轮询率 polling_rate** — 偏硬核
- ❌ **侧键数 side_buttons** — 89% 都是 2,几乎无鉴别力(猜中后剩 ~1306 只)
- ❌ **细分连接方式**(2.4G/蓝牙/有线的组合串)— 反而不如有线/无线直观

### 2.2 字段要加的
- ✅ **宽度 width**(168 取值,无缺失)— 鉴别力接近重量,大众能理解"长宽"
- ✅ **高度 height**(131 取值,无缺失)— 同上
- ✅ **传感器 sensor**(119 取值,缺 36)— 硬核但鉴别力强
- ✅ **hump 背部隆起**(4 取值,缺 1)— 只在揭晓卡片展示,**但参与同规格指纹判定**(见 §6);揭晓卡同时展示 `hand` 左右手。

### 2.3 字段要保留的(基础,倾向保留)
- ✅ **品牌 brand** — 最强鉴别力(猜中后剩 ~28 只)
- ✅ **产地 country / 大洲 continent** — 产地已全部补齐(缺失 0 条);产地不同但同大洲记黄牌(见 §6)
- ⏳ **尺寸 size / 形状 shape** — 保留(大众友好)
- ⏳ **重量 weight / 长度 length** — 保留(数值型,箭头提示)

### 2.4 数据与展示
- ✅ **连接方式**:用简单"有线/无线",不用细分组合串
- ✅ **Nintendo Joy-Con 2**:保留(手柄可当鼠标用,不剔除)
- ⏸ **image 图片**:搁置。当前只有文件名(1162 个)、无实际图片资源、无代码消费。后续有机会再从 eloshapes/品牌官网批量爬取,并在揭晓卡片渲染。

## 3. 当前产品方向(历史讨论,已被后续迭代取代)

> 本节写于难度分层实施之前。现状:分层已落地 —— 不再有「normal 全库」;三档难度池由 `mouse_difficulties` 成员表驱动(当前库 1617 只),管理端可按品牌/型号调档(`tier-assignment.json` 管线),字段集合保持三档统一。

**先做"全字段 + 全库"完整版,自己体验;不做初期的难度分字段降门槛。**

理由:
- 这是个小众外设圈子,受众本就偏硬核,先做入门降门槛(curated 简化)意义不大。
- 优先做出**完整、深度**的玩法,作者先自己玩,验证"好玩",再决定要不要给新手做简化。

### 对难度设计的影响
- 暂不实施"字段随难度分层"(方案 Y)。
- 先实现**统一一套完整字段 + normal 全库(1609 只)**给作者体验。
- beginner/easy 的字段或池子简化,等体验后再评估是否必要。

## 6. 后续落地的新机制(初版文档未覆盖)

- **同规格家族判定(specFingerprint)**:品牌、属地、大洲、形状、尺寸、重量、长度、有无线的布尔、宽、高、传感器、hump、手型共 13 项构成规格指纹(`server/src/services/gameService.ts` `specFingerprint()`);猜测与目标 `id` 不同但指纹一致时视为**同规格兄弟款,直接判胜**。这是对「胜负只认 id」规则的修订。
- **同大洲黄牌**:品牌属地不同、但大洲相同时,产地属性记 `close`(黄牌),而非红色。
- **联想池按难度过滤**:输入联想只提示当前难度池内的鼠标(无难度标签时退化为不过滤);查鼠标页仍搜全库。
- **停用开关是第四态但不是难度**:`is_enabled = false` 的鼠标退出所有难度池、联想与目标池(历史对局保留);难度键仍只有 easy/normal/hard 三个。
- **目标选取避近期重复**:60 分钟窗口内每人每难度最多记忆 20 只已遇目标,且至少保留 5 个候选(`server/src/services/targetSelection.ts`)。
